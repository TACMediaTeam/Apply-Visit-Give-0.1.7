# Apply · Visit · Give — asset checklist

## Must-have
1. HSSP logo: SVG, or a transparent PNG at least 600px (slot: `data-slot="hssp-logo"`)
2. College inquiry/application form embed code (`#form-college`)
3. HSSP application form embed code (`#form-summer`)
4. Visit request form embed code (`#form-visit`)
5. Giving widget embed code (`#give-widget`)
6. HSSP facts: eligibility, session dates, campus(es), deadline, cost/aid
7. Giving amounts and what each provides (3 tiers)
8. Confirmed links: application portal, visit page, giving page, plus a phone number if you want one shown

## Persuasion assets (these make the page convert)
9. Three short testimonials: a current student (college), an HSSP alum, and a donor or a student who received aid. Each needs a name, year, and permission to use.
10. Two or three verified proof stats, e.g. % of students receiving aid, average class size, outcomes or ranking
11. HSSP photos: 2–3 shots of high-schoolers in seminar, at chapel, and outdoors (all current photos show college students)
12. Giving hero photo: a student portrait or a moment of gratitude (optional, a chapel image is in place now)

## Nice-to-have
13. A short video loop (10–20 seconds) for any of the three doors
14. Analytics/pixel IDs for tracking which door is chosen
15. Final URL / where this page will be hosted
